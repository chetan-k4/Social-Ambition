# Social-Ambition

## Skills

This repo vendors the [Superpowers](https://github.com/obra/superpowers) skills library (MIT, Jesse Vincent; synced from commit bb92a77) in `.claude/skills/`.

At the start of every session, invoke the `using-superpowers` skill and follow it: check for a relevant skill before starting any task (brainstorming before building, writing-plans before multi-step work, test-driven-development, systematic-debugging, verification-before-completion, etc.).
